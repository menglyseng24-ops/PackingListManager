# Packing List Manager App
# Features
- Allow users to make a packing list by adding item, removing item, viewing and finishing the list with a simple prompt.
- Safety nets for falsy value, invalid value in the list, and empty list.
# How it works
- The program will start and prompt the user between adding item, removing item, viewing the list or finishing up the list using a while loop.
- If the user types in add, another prompt will pop up asking the user what they want to add.
- If the user types in remove, another prompt will pop up asking the user what they want to remove.
- If the user types view, the current list will pop up.
- if the user types finish, the finished list will pop up.
# Code Example
- First import the code into your VS code, then run the program.
- Type in add then an item you want to add.
- Type in remove then an item you want to remove.
- Type in view then the current list will pop up.
- Type in finish then the list will be all finished.
